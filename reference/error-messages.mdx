## Workload Deployment Errors

- `Error: exitCode: 1 message: standard_init_linux.go:228: exec user process caused: exec format error`
  - The incorrect platform was used to build the configured image. Control Plane requires the image target `amd64`. Refer to the [Push an Image Guide](/guides/push-image#step-2-build-a-new-image-using-docker-and-a-dockerfile-optional) for additional details.

- `OOMKilled: exitCode: 137 message: ""`
  - The container exceeded its `memory` limit and was killed by the kernel (`SIGKILL`, signal 9) — exit code 137 is 128 + 9. Control Plane reports this as `restarts.reason: OOMKilled` and `restarts.exitCode: 137` in the workload's [deployment status](/reference/deployment#container-status), and it also appears in the workload's events. Fix it by raising the container's `memory` in the [workload configuration](/reference/workload/containers#resources) (raise `cpu` alongside it, since a container's memory in MiB can be at most 8 times its CPU in millicores) or by reducing the application's memory usage. If [Capacity AI](/reference/workload/capacity) is enabled, set `minMemory` as a floor so it isn't sized down too far.
