Manage sandbox images

For a detailed overview, please visit the [sandbox image's](/reference/sandbox/image) reference page.

Refer to the [sandbox images guide](/guides/sandbox/sandbox-images) for additional details.



```none
cpln sandboximage [SUBCOMMAND]
```




```text
Commands:
  cpln sandboximage access-report <ref>  Show the access report for the referenced sandbox image
  cpln sandboximage audit [ref]          Retrieve audit trail events for the referenced sandbox image
  cpln sandboximage buildlog <ref>       Print the referenced sandbox image's latest build log
  cpln sandboximage clone <ref>          Create a copy of the referenced sandbox image; the copy builds under your token  [aliases: copy]
  cpln sandboximage create               Create a sandbox image and submit its build
  cpln sandboximage delete <ref...>      Delete one or more referenced sandbox images
  cpln sandboximage edit <ref>           Edit the referenced sandbox image, as YAML, within an editor
  cpln sandboximage eventlog <ref>       Show the event log of the referenced sandbox image  [aliases: log]
  cpln sandboximage get [ref...]         Retrieve one or more referenced sandbox images
  cpln sandboximage patch <ref>          Update the referenced sandbox image's metadata using an input file
  cpln sandboximage permissions          Show the grantable permissions for a sandbox image object type
  cpln sandboximage query                Find all the sandbox images based on the given query
  cpln sandboximage rebuild <ref...>     Rebuild one or more referenced sandbox images from their current recipe
  cpln sandboximage tag <ref...>         Manage the tags belonging to one or more referenced sandbox images
  cpln sandboximage update <ref>         Update properties of the referenced sandbox image

Options:
  --help  Show help  [boolean]
```

#### sandboximage create


Create a sandbox image and submit its build



**Usage**

```none
cpln sandboximage create --name SANDBOX_IMAGE_NAME [OPTIONS]
```

<Note>

The command returns as soon as the build is submitted. Follow the build with [sandboximage buildlog](#sandboximage-buildlog), and read its phase with [sandboximage get](#sandboximage-get).

</Note>

<Tip>

`--type dev`, the default, builds an image for dev sandboxes. `--type agent` builds an image for sessions and needs `--base-image`.

</Tip>


<Accordion title="Reference">

```text
Command options:
  --name                 The name of the new sandbox image.  [required]
  --description, --desc  Optional description, defaults to the name if not set.
  --base-image           The image the sandbox layer is built onto: a link to an org image (//image/<name>:<tag>) or a full image reference. Omit it to build on the standard sandbox base. Build one with 'cpln image build'.
  --image-tag            The tag of the built image in the org registry. Defaults to latest.
  --type                 dev (default) builds the base plus the sandbox layer, for dev sandboxes; agent copies the base alone, for sessions, and needs --base-image.  [choices: "dev", "agent"]
  --tag                  Attach tags (e.g., --tag drink=water)
  --dry-run              Validate the request and print the resource that would be written, without writing it. Defaults the output format to yaml-slim  [boolean]

Context options:

  --org      Override the organization. The default organization can be set in your profile by using the `cpln profile update` command

Format options:
  --output, -o  Set the output format  [choices: "text", "json", "yaml", "json-slim", "yaml-slim", "tf", "crd", "names"]
  --color       Colorize the output  [boolean] [default: true]
  --ts          Timestamp format if the output format is text (e.g., --output=text)  [choices: "iso", "local", "age"]
  --max         Maximum number of records to show. A value less than 1 will return all records.  [number] [default: 50]

Request options:
  --token         Override the authorization token
  --endpoint      Override the API URL
  --insecure, -k  Ignore TLS errors  [boolean]
```

<Accordion title="Options">

- The `--set` option allows the modification of the following sandbox image properties:
  - `description`
    - Description of the sandbox image
    - Type: string
  - `tags`
    - Tags (key=value) associated with the sandbox image
    - Type: string
  - `spec.base.image`
    - The image the sandbox layer is built onto: a link to an org image (`//image/NAME:TAG`) or a full image reference
    - Type: string
  - `spec.tag`
    - The tag of the built image in the org registry
    - Default: latest
    - Type: string
  - `spec.type`
    - The type of the sandbox image
    - Choices: `dev`, `agent`
    - Default: dev
    - Type: string


</Accordion>
