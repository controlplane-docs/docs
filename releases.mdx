## Subscribe to Release Announcements

<AccordionGroup>
  <Accordion title="RSS feed" icon="rss">
    Point a feed reader, or Slack's `/feed subscribe` command, at the platform stream's feed: `https://github.com/controlplane-com/product-updates/releases.atom`. An RSS-to-email service turns the same feed into inbox notifications.
  </Accordion>
  <Accordion title="GitHub notifications" icon="github">
    On the [product-updates](https://github.com/controlplane-com/product-updates) repository, select `Watch`, then `Custom`, and check `Releases`. The GitHub mobile app can deliver these as push notifications.
  </Accordion>
  <Accordion title="Provider repositories" icon="code-branch">
    The RSS and watch options work for any GitHub repository, including the Terraform and Pulumi streams: append `.atom` to a releases page URL for its feed, or watch the repository.
  </Accordion>
</AccordionGroup>
