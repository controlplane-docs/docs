## What you build

The finished system, tagged with the part of the series that creates each piece:

<img src="/images/quickstart/series.svg" alt="A user's browser reaches the domain example.com, which routes to the workload frontend, which calls the workload api, which connects to the workload db-postgres. frontend and api run in the GVC quickstart-gvc spanning AWS and GCP; db-postgres runs in the GVC quickstart-db on AWS. The secret db-credentials is read by api and db-postgres, and logs, metrics, and traces are collected for every workload. Six parts, one system: a frontend, an API, and a database, observed end to end." style={{maxWidth:'720px',width:'100%',margin:'1.75rem auto',display:'block'}} />

<Note>
You need an [org](/reference/org) to deploy into. If you don't have one yet, [sign up](https://console.cpln.io/signup) for Control Plane: the Console walks you through creating a [billing account](/concepts/billing) and your first org.
</Note>


## The six parts

<CardGroup cols={2}>
  <Card title="1. Deploy your first workload" icon="rocket" href="/quickstart/quick-start-1-deploy-workload">
    A GVC across AWS and GCP, one workload with a replica in each, and one endpoint that routes to the nearest healthy location.
  </Card>
  <Card title="2. Deploy your own application" icon="rocket" href="/quickstart/quick-start-2-deploy-application">
    Build the frontend from source into your org's private registry, run it, then ship a change.
  </Card>
  <Card title="3. Configure a custom domain" icon="globe" href="/quickstart/quick-start-3-custom-domain">
    Put your own domain in front of the frontend, with a certificate Control Plane issues and renews.
  </Card>
  <Card title="4. Service-to-service communication" icon="arrows-left-right" href="/quickstart/quick-start-4-service-to-service">
    Build the API, keep it off the internet, and let the frontend reach it by name through the mesh.
  </Card>
  <Card title="5. Add a database and wire its secret" icon="database" href="/quickstart/quick-start-5-database-secrets">
    Add PostgreSQL from the Template Catalog and deliver its credentials through an identity, a policy, and a secret.
  </Card>
  <Card title="6. Observe your workload" icon="chart-line" href="/quickstart/quick-start-6-observe-workload">
    Follow one request through the logs of both workloads, read the metrics, and open a trace that spans them.
  </Card>
</CardGroup>
